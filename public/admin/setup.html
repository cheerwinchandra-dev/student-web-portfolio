Admin password setup

Creates the two values Vercel needs. Everything happens in this browser; nothing is sent anywhere.

At least 10 characters with letters and numbers, not your username. Use a password that isn’t written anywhere else, such as a GitHub README.

  1. In Vercel, open your project → Settings → Environment Variables.
  2. Add ADMIN_PASSWORD_HASH and CRON_SECRET with the values above (all environments).
  3. Open Deployments → the latest one → ⋯ → Redeploy.
  4. Sign in at /login with username cheerwin and the password you just typed.
  5. Open Security and turn on two-step sign-in with an authenticator app. Your inbox opens once it is on.
